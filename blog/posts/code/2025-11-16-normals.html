Nature of Code - Normals

November 16, 2025

Normal distribution in TIC-80 using Janet. I converted the approach p5.js uses for normal randoms to Janet and displayed the result using the growing vertical bars like in previous examples.

Here's the code and the cartridge:

# title:   Normal Distribution
# author:  clockworkmartian
# desc:    from nature of code chatper 0
# site:    none
# license: MIT License
# version: 0.1
# script: janet
# strict:  true

(use tic80)
(var randomCounts @[])
(def total 60)
(var y2 0)
(var gprev false)

(defn randomGaussian [mean sd]
 (var y1 nil)
 (if gprev
  (do 
   (set y1 y2) 
   (set gprev false))
  (do
   (var x1 nil)
   (var x2 nil)
   (var w 1)
   (while (>= w 1)
    (set x1 (- (* (math/random) 2) 1))
    (set x2 (- (* (math/random) 2) 1))
    (set w (+ (* x1 x1) (* x2 x2))))
   (set w (math/sqrt 
    (/ (* -2 (math/log w)) w)))
   (set y1 (* x1 w))
   (set y2 (* x2 w))
   (set gprev true)))
   (+ (* y1 sd) mean))

(defn drawRectangles []
 (def index 
  (math/floor (randomGaussian 30 3)))
 (def w (math/ceil (/ 240 total)))
 (++ (randomCounts index))
 (for x 0 total
  (rect (* x w)
        (- 136 (randomCounts x))
        (- w 1)
        (randomCounts x)
        8)))

(defn BOOT []
 (repeat total 
  (array/push randomCounts 0)))

(defn TIC []
 (cls 13)
 (print "Normal Distribution (Janet)" 5 5)
 (drawRectangles))
